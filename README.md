# VERITAS Intelligence — Corporate Investigation Website

This is a complete static multi-page website inspired by the functional patterns discussed from NARADism (service architecture, case-study storytelling, technology/intelligence positioning, FAQ and confidential enquiry flow) while using an original visual system, brand, copy and layout.

## Included
- Home 01
- Home 02 (unique layout)
- Services
- Background Checks
- Fraud Investigation
- M&A Due Diligence
- Corporate Intelligence
- About
- Case Studies
- Insights
- Confidential Enquiry
- Persistent light/dark theme switch using localStorage
- Responsive mobile navigation
- No login, signup or dashboard
- Unique image URL on every image used; no image is reused across pages

## Image licensing note
Images are linked from Unsplash and were selected from pages marked free to use under the Unsplash License. The site uses remote image URLs so the ZIP stays lightweight. Before production deployment, download/host the selected assets locally and retain attribution/licensing records as appropriate.

## Main reference
NARADism: https://naradism.com/
Its current site presents service-led navigation, illustrative case studies, technology/intelligence positioning, FAQs and a confidential consultation flow. The reference site is used for functional inspiration only.
